# 优秀作业入库模板

## 入库目的

用于把通过验收的学员作业转成课堂样例、结课展示、招生证据、企业内训样板或工具字段改进素材。入库前必须完成脱敏、授权和人工边界确认。

- Codex 辅助输出：

## 脱敏检查

- 客户名称已替换。
- 联系方式已删除。
- 合同、发票、订单编号已替换。
- 成本、底价、利润和真实成交价已删除或改成示例。
- 付款、银行、报关、清关和内部审批信息已删除。
- 企业内部 SOP、客户投诉和法律争议信息未公开。

## 授权状态

- 学员是否同意用于课堂点评：
- 学员是否同意用于公开展示：
- 企业资料是否获得负责人授权：
- 授权范围：内部课堂 / 公开课 / 招生页面 / 企业服务案例 / 不允许公开

## 入库位置

- 课堂样例：

- 指令库质量样例：

## 禁止事项

- 不把未通过验收的作业包装成优秀案例。
- 不把课堂样例包装成真实成交成果。
- 不公开展示未授权学员或企业资料。
- 不用 AI 自动判断是否可公开，必须由负责人确认。
