# 询盘识别与回复工具开发规格书

## 1. 工具定位

- 工具名称：询盘识别与回复工具
- 关联课程：回询盘、报价前确认、集成房屋案例
- 适用用户：外贸业务员、业务主管、试听课老师
- 发布阶段：V2 轻交互优先
- 第一演示案例：20ft 可扩展集成房屋出口项目

## 2. 业务场景

客户发来英文询盘：沙特建筑承包商需要 80 套 20ft 可扩展集成房屋，用于工地住宿营地，要求 CIF Jeddah，并关注卫浴、电气、保温、交期、装柜数量、安装指导和质保。

业务员需要在报价前快速完成：

- 识别客户已提供的信息。
- 找出报价前必须补问的字段。
- 提醒不能自动承诺的风险点。
- 生成一版可人工修改的英文回复草稿。

## 3. 输入字段

- 原始客户询盘。
- 产品名称和基础资料。
- 公司介绍或回复口径。
- 常见补问字段库。
- 人工确认边界。

## 4. Codex 角色

Codex 只负责：

- 整理原始询盘。
- 识别数量、产品、目的港、贸易术语和配置。
- 匹配缺失字段。
- 生成补问问题和回复草稿。
- 提醒价格、交期、付款、认证和 DDP 风险。

Codex 不负责：

- 自动给最终价格。
- 自动承诺交期。
- 自动决定付款方式。
- 自动承诺认证、安装、清关或当地合规。

## 5. 输出结果

- 已知需求摘要。
- 缺失字段清单。
- 报价前补问问题。
- 人工确认边界。
- 英文回复草稿。

## 6. 验收标准

- 输入集成房屋样例询盘后，能识别数量 80 units、CIF Jeddah、卫浴、电气、保温和工地营地场景。
- 缺失字段不少于 4 项，至少包含项目地点、布局图纸、墙板材料、电气标准或安装责任。
- 输出必须包含价格、交期、认证和 DDP 的人工确认边界。
- 英文回复草稿不能包含未经确认的价格、交期、付款承诺或认证承诺。
- 移动端结果区不横向溢出，按钮和文本不互相遮挡。

## 7. 后续迭代

- V1：静态模板和课堂演示。
- V2：网页内粘贴询盘并生成结构化结果。
- V3：支持导出 Markdown、复制邮件草稿、保存课堂样例。
- V4：允许企业上传脱敏字段库，生成企业专属询盘识别器。
