FT 外贸 Codex 训练平台Prompt Library

维护规则

每条指令都要说明适用场景、输入数据、输出结果、关联工具和风险提醒。

Prompt System

指令库交付标准

指令不是零散话术，而是课程、工具和作业之间的连接层。每条指令都要能从真实业务输入，产出可复用的工具结果。

Prompt Workflow

课堂指令使用流程

老师按这套流程讲解，学员按这套流程替换成自己的产品和客户资料。

Prompt Composer

外贸 Codex 指令组装器

选择业务场景、行业资料、输出格式和人工边界，生成可复制、可导出、可课堂验收的 Codex 指令。

Prompt Deployment Desk

指令部署与验收台

把指令从课堂组装推进到作业、工具规格、招生证据、资源跟进和企业 SOP，明确输入、输出、质量门槛和人工边界。

Performance Review

指令效果复盘与优化台

指令进入课堂、作业、工具或企业 SOP 后，按输出证据、问题类型、风险等级和下一步去向，判断保留扩展、返修、暂缓或回滚。

Prompt Pack

集成房屋课堂指令包

把零散指令组合成课前准备、客户开发、询盘识别、报价订单、单证检查和风险复盘的完整演示路径。

Governance Board

指令治理与行业替换台

后续新增指令、学员行业替换和企业内训指令，都要经过立项、输入校验、主案例验证、质量门槛、作业验收和版本回写。

Prompt Library

当前指令资产清单

每条指令都维护业务场景、输入资料、输出结果、人工确认边界和质量检查，后续新增行业时按同一字段扩展。
