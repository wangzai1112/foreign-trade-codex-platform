FT 外贸 Codex 训练平台Operating Playbook

维护原则

网站不是一次性落地页，而是培训公司长期内容、工具、案例和企业服务的运营系统。

新增内容规则

先确认业务场景和交付物，再补课程页面、工具预览、指令和资源承接。

Platform Status

长期平台建设指标

这些指标用于判断网站是否已经从单门课程，升级为可持续运营的培训公司平台。

First Draft Launch Desk

初稿发布就绪台

准备把网站交给内部团队、试听课学员、报名咨询或企业客户查看前，先检查页面证据、UI 状态、下载资产、商业边界和下一步动作。

Visual QA Gate

视觉风格与响应式发布验收台

每次新增页面、工具、资源或销售入口后，按商务简约、液态毛玻璃、桌面/手机无溢出、关键交互和人工确认边界做发布前验收。

Health Audit Desk

平台健康审计与证据台

按招生、课程、课堂、案例、工具、指令、资源、企业服务和运营治理维度定期检查，生成证据路线、整改动作和人工确认边界。

Remediation Router

审计整改执行链路由台

把健康审计的 Hold、Amber、审批和发布前缺口，路由到版本回写、工具 Sprint、案例 Sprint、资源补齐、企业 SOP 或治理复核，形成可执行整改 Brief。

Remediation Review

整改复查与验收闭环台

整改完成后在这里复查证据、验证结果、风险关闭和业务影响，决定是否验收关闭、返修、进入人工审批或回到下期版本池。

Company Ops Console

培训公司日常运营总控台

把招生、课堂、学员成果、企业服务、工具迭代和版本发布转成每天可执行、可复制、可复盘的运营 Brief。

Tool Sprint Command

工具 Sprint 执行与验收台

把工具产品化 Brief 接到开发排期、课堂验证、企业审批、上线验收和版本回写，确保工具不是一次性演示，而是能长期维护的课程与企业服务资产。

Goal Compliance

长期平台目标执行矩阵

把当前建设目标逐条转成页面证据、上线门槛、负责人和更新触发条件，后续每次新增课程、工具、案例或企业服务都按这里验收。

Evidence Coverage Index

全站证据覆盖索引

把招生、课程、课堂、案例、工具、指令、资源、企业和运营治理统一映射到页面、数据文件、下载资产、Codex 辅助事项和人工确认门槛。

Self Check

新增模块合规自检台

新增页面、课程、工具、资源或企业服务前，先在这里确认是否符合长期平台标准，再进入发布审计。

Release Board

平台发布与维护看板

每次新增课程、工具、指令、资源或企业服务，都按这里检查数据、页面、下载、转化和人工边界。

Writeback Router

版本回写与维护日志路由台

把工具发布、课堂反馈、招生顾虑、资源下载、企业交付和行业案例信号路由到对应页面、数据文件、下载资产和维护日志，确保每次运营反馈都能闭环。

Maintenance Log Builder

维护日志与版本发布说明生成器

把每次页面、工具、资源、课程、案例或企业服务更新，整理成可复制的维护日志、发布说明、验证记录和下期回写任务。

Version Review

课程版本迭代与上新评审台

把招生顾虑、课堂卡点、工具需求、行业案例和企业咨询统一评审，决定本期更新哪些课程、页面、下载和工具规格。

Data Governance

资料脱敏、授权与公开展示治理台

统一管理学员和企业资料如何接收、脱敏、授权、用于课堂、进入案例或作为招生证据，避免商业机密和隐私风险。

Commercial Packaging

课程产品 SKU、交付承诺与复购治理台

把免费资料、系统课、陪跑、企业诊断、团队内训和工具共建统一成产品包，明确交付物、证据页面、销售边界和后续复购动作。

Offer Boundary Review

商业产品包承诺边界评审器

在销售咨询、付款确认、企业签约或续费复盘前，把产品包、证据、范围、风险和下一步动作组合成可交付、可验收、不过度承诺的确认 Brief。

Core Principles

所有课程和页面都必须遵循的原则

后续新增行业、课程、工具和资料包时，先按这些原则检查，再进入页面开发。

Page Standards

各类页面的建设标准

每类页面都有必备内容、负责人和上线门槛，避免后续维护时变成零散资料堆积。

Operating Flow

从业务问题到课程产品的运营流程

平台后续迭代应从真实业务问题开始，最终沉淀为课程、案例、工具、资源和企业服务。

Maintenance Cadence

平台日常维护节奏

培训公司后续运营不能只等大版本更新，要把招生反馈、课堂作业、工具问题和企业咨询定期转成页面和数据更新。

Content Ops Matrix

内容更新责任矩阵

每类页面都要知道什么情况需要更新、改哪个数据文件、由谁负责，以及上线前如何验证。

Release Checklist

上线前检查清单

这部分用于课程内容、页面发布、课堂使用和商业推广前的质量检查。

Roadmap

后续建设路线图

先把集成房屋样板跑通，再逐步交互化工具、扩展行业案例和产品化企业服务。

Next Action

下一步按指南继续补企业服务和交互工具

运营指南确定后，后续每次新增页面、工具或资源，都可以按这里的检查项完成内容和上线验证。
