FT 外贸 Codex 训练平台Tool Library

开发策略

先模板化，再网页化，最后交互化。第一批重点覆盖产品资料、客户开发、询盘、报价、订单、单证和付款风险。

Interactive Demos

课堂演示工具区

从产品资料、客户开发、询盘识别、报价测算、订单跟进、单证检查到付款风险，演示如何把重复性判断转成可复制的业务动作。工具只做结构化辅助，不替代人工确认。

Tool Library

第一批工具规划

Build Specs

工具开发规格书与复制标准

工具在开发前先写清业务场景、输入字段、输出结果、验收标准和人工边界，后续才能稳定复制到更多行业案例。

Demand Scoring

工具需求评分与排期台

把课堂高频问题、学员作业、企业诊断和招生反馈转成可评分工具候选，明确先做模板、轻交互还是暂缓开发。

Productization Brief

工具产品化 Brief 生成器

把一个重复性的外贸工作流快速判断为模板包、静态原型、轻交互工具或企业定制项目，并生成课程、开发、销售和人工边界都能使用的产品化 brief。

Launch Board

工具产品化路线与上线验收台

工具不直接从想法进入开发，而是从课堂高频动作、字段样例、静态原型、轻交互开发、上线验收和行业复制逐步推进。

Classroom Acceptance

轻交互工具课堂验收闭环

把已上线的课堂工具逐项放进试讲、作业、导出、人工边界和版本回写检查，判断是否进入正式课、试听课、企业内训或继续返修。

Sample Validation

真实样例替换验收台

把 7 个轻交互工具放到学员或企业脱敏样例里复测，确认输入证据、输出质量、人工边界、页面去向和版本回写动作，避免工具只适合集成房屋默认样例。

Tool Mockups

静态工具界面预览

这些预览用于课程展示、落地页截图和早期用户验证。后续确认需求后，再升级成交互工具。
