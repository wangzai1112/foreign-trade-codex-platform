使用原则

先判断业务动作是否适合工具化，再决定用提示词、表格、课堂演示器还是企业工作台承接。

Automation Snapshot

外贸流程自动化总览

自动化地图用于销售讲解、课堂设计、工具开发和企业诊断，统一说明 Codex 能做什么、产出什么、谁来确认。

Workflow Map

8 个业务环节的 Codex 自动化边界

每个环节都必须同时写清业务痛点、Codex 角色、工具产出、课程入口和人工确认边界。

Automation Levels

自动化等级和禁止替代边界

不是所有动作都应该自动化。课程和企业服务必须把可自动化、辅助判断和禁止替代分开讲。

Scope Assessment

自动化范围判定台

每个真实业务动作进入工具、指令、资源或企业服务前，先判断输入是否可用、输出风险多大、人工确认人是否明确，以及是否适合自动化。

Tool Priority

工具开发优先级

优先开发课堂高频、字段清晰、人工边界明确的工具，再逐步升级到企业工作台。

Implementation Flow

从重复劳动到可复制工具的落地流程

所有工具都先从真实业务问题开始，再转成规格卡、课堂演示器和可复用模块。

Risk Gates

自动化上线前的风险检查口

只要涉及报价、单证、客户开发、企业案例和专业判断，就必须提前设置人工确认人。

Integrated House Validation

用集成房屋案例验证自动化节点

所有自动化设计先用集成房屋出口案例跑一遍，再替换到其他行业和企业客户。
